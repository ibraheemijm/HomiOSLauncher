# Homi OS Launcher

**Homi OS Launcher 1.1.0** — مشغّل أندرويد عربي بتصميم زجاجي مستقبلي يجمع توزيع التطبيقات متعدد الصفحات مع بطاقات شفافة وخلفيات قابلة للتخصيص.

## الوظائف

### الشاشة الرئيسية
- صفحات أفقية قابلة للسحب مع مؤشرات صفحات.
- اختيار عدد الأعمدة من 3 إلى 6، وأربع صفوف كحد افتراضي لكل صفحة.
- تغيير حجم أيقونات الشاشة الرئيسية.
- إظهار أسماء التطبيقات أو إخفاؤها.
- ترتيب التطبيقات بالسحب والإفلات مع حفظ الترتيب.
- ساعة وتاريخ باللغة العربية، وشريط سفلي ثابت حتى أربعة تطبيقات.

### المجلدات
- إنشاء مجلدات وتسمية كل مجلد.
- عرض محتويات المجلد في شبكة أيقونات.
- فتح التطبيق من داخل المجلد.
- إعادة تسمية المجلد، وتعديل محتوياته، أو حذفه دون حذف التطبيقات من الهاتف.
- المجلدات محفوظة محلياً على الجهاز.

### مكتبة التطبيقات
- البحث باسم التطبيق أو اسم الحزمة.
- تخصيص عدد الأعمدة من 3 إلى 6.
- تخصيص حجم الأيقونات.
- الضغط المطول على التطبيق لإضافته إلى الشريط السفلي أو إزالته.

### لوحة النظام والإشعارات (الإصدار 1.2.0)
- لوحة تحكم مبنية بـ Kotlin وJetpack Compose يمكن فتحها من إعدادات المشغّل.
- تعديل مستوى صوت الوسائط مباشرة.
- التحكم بالسطوع بعد منح صلاحية تعديل إعدادات النظام.
- اختصارات تفتح صفحات إعدادات Wi-Fi وBluetooth الأصلية؛ لا يحاول التطبيق تجاوز قيود أندرويد لتبديلها مباشرة.
- خدمة `NotificationListenerService` تعرض عناوين ونصوص الإشعارات النشطة بعد تفعيل وصول الإشعارات يدوياً.
- لا تحل اللوحة محل ستارة الإشعارات الأصلية أو شاشة القفل، ولا تمنح صلاحيات نظام خاصة.

### المظهر والتخصيص
- ألوان رئيسية متعددة، ووضع فاتح أو داكن.
- اختيار صورة خلفية من الهاتف واستخراج لون بارز منها.
- تأثير ضبابي للخلفية على Android 12 وما بعده.
- تغيير حجم الساعة.
- إعادة ضبط تخصيصات المشغّل مع الحفاظ على المجلدات.

### الخصوصية والتوافق
- لا يتطلب اتصالاً بالإنترنت لتشغيل الواجهة الأساسية.
- الإعدادات والمفضلة والمجلدات محفوظة محلياً.
- `minSdk 23` و`targetSdk 35`.
- معرف الحزمة: `com.homi.oslauncher`.

## تنزيل APK

1. افتح [أحدث عمليات البناء في GitHub Actions](https://github.com/ibraheemijm/HomiOSLauncher/actions).
2. افتح أحدث تشغيل مكتمل بنتيجة **Success**.
3. من قسم **Artifacts** نزّل `HomiOSLauncher-APK`.
4. فك ضغط ZIP وثبّت `app-debug.apk`.
5. من إعدادات أندرويد اختر **Homi OS** ضمن تطبيق الشاشة الرئيسية الافتراضي.

إذا كان البناء قيد التنفيذ أو فشل، فلن تكون هناك نسخة جديدة صالحة للتنزيل من ذلك التشغيل. تستخدم عمليات البناء القادمة مفتاح توقيع Debug ثابتاً محفوظاً في GitHub Actions حتى تبقى التحديثات اللاحقة قابلة للتثبيت فوق بعضها. قد يظل التحديث الأول من بناء قديم موقّع بمفتاح مختلف بحاجة إلى إزالة النسخة القديمة؛ لا تحذفها قبل التأكد من عدم وجود بيانات محلية تريد الاحتفاظ بها.

## البناء من المصدر

المتطلبات: JDK 17 وAndroid SDK يدعم API 35 وGradle.

```bash
gradle assembleDebug
```

مسار الناتج:

```
app/build/outputs/apk/debug/app-debug.apk
```

## حالة الإصدار

هذا إصدار تطوير قابل للتثبيت، وليس إصداراً تم التحقق منه على كل أجهزة أندرويد. اجتياز GitHub Actions يثبت نجاح التجميع، لكنه لا يغني عن اختبار التشغيل الفعلي على أجهزة مختلفة. ما زالت بعض وظائف المشغّلات المتقدمة مثل دعم widgets النظامية، وحزم الأيقونات، والنسخ الاحتياطي/الاستعادة، واختبارات الأجهزة الفعلية خارج نطاق هذه النسخة. لوحة النظام والإشعارات الجديدة تحتاج اختباراً فعلياً على الهاتف قبل اعتبارها مستقرة.

واجهة المستخدم الحالية عربية.
