# Homi OS Launcher

**واجهة أندرويد بديلة بتصميم زجاجي مستقبلي** تجمع بين توزيع الأيقونات المستوحى من iOS وشفافية الواجهات المستوحاة من Windows.

## المزايا الحالية

- شاشة رئيسية بأربع أعمدة، مع صفحات أفقية قابلة للسحب؛ كل صفحة تعرض حتى 16 تطبيقاً.
- شريط سفلي ثابت يضم حتى أربعة تطبيقات مفضلة.
- في مكتبة التطبيقات: اضغط مطولاً على التطبيق لإضافته إلى الشريط السفلي أو إزالته منه.
- في الشاشة الرئيسية: اضغط مطولاً على الأيقونة واسحبها إلى مكان تطبيق آخر لإعادة ترتيبها؛ يُحفظ الترتيب تلقائياً.
- إنشاء مجلدات تطبيقات، وفتحها، وإعادة تسميتها، وتعديل محتوياتها أو حذفها دون حذف التطبيقات من الهاتف.
- مكتبة تطبيقات بخمسة أعمدة مع البحث.
- ساعة وتاريخ باللغة العربية.
- اختيار صورة خلفية من الهاتف، مع استخراج لون بارز منها تلقائياً.
- تأثير ضبابي للخلفية على Android 12 وما بعده، مع شفافية للبطاقات.
- إعدادات لتغيير اللون الرئيسي وحجم الساعة والوضع الفاتح أو الداكن.
- دعم Android 6.0 (API 23) وما بعده وفق إعدادات المشروع.

## تنزيل نسخة تجريبية APK

1. افتح [صفحة GitHub Actions](https://github.com/ibraheemijm/HomiOSLauncher/actions).
2. اختر أحدث تشغيل ناجح باسم **Build Homi OS Launcher APK**.
3. من قسم **Artifacts** نزّل الملف **HomiOSLauncher-APK**.
4. فك ضغط الملف ZIP على الهاتف وثبّت `app-debug.apk`. قد يطلب Android السماح بالتثبيت من هذا المصدر.
5. بعد التثبيت، اضغط زر الصفحة الرئيسية واختر **Homi OS** كمشغّل افتراضي.

إذا لم يظهر Artifact، فتحقق من أن التشغيل اكتمل بنجاح؛ التشغيل الذي ما زال قيد التنفيذ لا يحتوي على نسخة جاهزة بعد.

## البناء من المصدر

المتطلبات: JDK 17 وAndroid SDK يدعم API 35 وGradle.

```bash
gradle assembleDebug
```

توجد النسخة الناتجة في:

```
app/build/outputs/apk/debug/app-debug.apk
```

## الحالة

المشروع قيد التطوير. تُبنى نسخة Debug تلقائياً عند كل دفع إلى فرع `main`. قبل اعتبار إصدار ما مستقراً، يجب اختباره على هاتف فعلي للتحقق من اختيار المشغّل الافتراضي، واللمس، والخلفيات، وتوافق أحجام الشاشات.

## اللغة

واجهة المستخدم الحالية عربية، واسم الحزمة هو `com.homi.oslauncher`.
